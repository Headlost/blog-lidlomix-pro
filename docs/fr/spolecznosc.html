Règles du forum
  1. Restez respectueux. Choisissez la bonne rubrique et vérifiez si le sujet existe déjà.
  2. Décrivez votre expérience. Évitez les liens, la publicité et les fichiers d’installation. Pour un problème, indiquez le modèle, la version et les étapes.
  3. Retirez les données de compte, les adresses e-mail, les numéros de série, les noms de réseau et les codes d’association. Les consignes pour contourner les protections du robot sont exclues.
  4. Dans la rubrique Recettes, ajoutez le lien public dans le champ de la source.

La publication dépend des paramètres de modération.
